# Install

## From PyPI

```bash
pip install splunkctl
```

## From source

```bash
git clone https://github.com/dannyota/splunkctl.git
cd splunkctl
pip install -e .
```

## Verify

```bash
splunkctl version
```

## Requirements

- Python 3.13+
- A running Splunk Enterprise instance with the REST API enabled (port 8089)
